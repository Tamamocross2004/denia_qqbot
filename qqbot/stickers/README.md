# 表情包目录

按情绪分文件夹，模型输出 `[[em:标签]]` 时，bot 会从这个文件夹里**随机挑一张**发出去。

```
stickers/
├── 困/      6 张
├── 开心/    11 张
└── 无语/    19 张
```

标签只有三个。「嫌弃」已经并进「无语」——两者边界太模糊，分开只会让素材分散，模型也分不清，见下面「素材来源」。

## 放图的规矩

- 支持的格式：`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`
- **文件夹名就是标签名**，中文没问题，和 `config.json` 里 prompt 写的标签一一对应
- 同一个文件夹放多张，每次随机挑一张，不会重复腻
- 建议 **240×240 左右、单张 300KB 以内**。图片会转成 base64 塞进消息，太大容易发不出去
- 文件名随意，`01.png` / `困死了.gif` 都行

## 加新标签

比如想加「生气」：

1. 建 `stickers/生气/`，扔几张图进去
2. 打开 `qqbot/config.json`，在 `system_prompt` 里那行表情标记后面补上 `[[em:生气]]`
3. 存盘即生效，不用重启

**只建文件夹不改 prompt，模型不会主动用那个标签。**

## 素材来源

全部是达妮娅本人的画面，来自官方 PV 截图和玩家二创。**张数以目录实际为准**，随时可以补：

```bash
cd D:/code/deepseek/qqbot
for d in stickers/*/; do echo "$d $(ls -1 "$d" | wc -l)"; done
```

| 目录 | 内容 |
|---|---|
| `困/` | 闭眼、趴着、半睡半醒那类 |
| `开心/` | 比心、微笑、爱心、动图 |
| `无语/` | 侧脸、冷淡、懒得理人、嫌弃脸全在这一起 |

- **PV 截图**：1280×590 宽幅、底部带字幕 → 裁掉底部 10% → 中心裁方 → 320×320 → JPEG q82（15–22KB）
- **二创 Q 版**：保留透明背景存 PNG，缩到 320×320
- **动图**：240×240、隔帧取、48–64 色，3–9MB 压到 440–736KB

**二创素材的版权归原作者**，自己群里玩没问题，别拿去商用或二次传播。

### 为什么「嫌弃」并进「无语」

原先分了四个标签，但「无语」和「嫌弃」在画面上几乎分不开——都是冷脸、撇嘴、懒得看你。结果是两边素材都薄，同一个表情反复出现。

合并后 `无语/` 有 19 张，随机性明显好很多。代码里 `STICKER_HINTS` 也把「烦死、讨厌、懒得、啧、蠢、傻」这些词全归到了无语，`system_prompt` 的标签列表只留 `[[em:困]] [[em:开心]] [[em:无语]]`。

**以后再分新标签要有明确判据**，别凭感觉。比如「困」和「开心」分得开（闭眼 vs 笑），这种才值得拆。

## 找素材的经验

- **官方联动贴纸里没有达妮娅**（鸣潮 ×「いらすとや」那套 16 张早于她登场，而且全是日文），别浪费时间
- **库街区表情包专区抓不到**：纯 SPA，HTML 只有 5KB，数据全在需要签名的接口后面
- **百度图片明确拒绝爬虫**：返回 `{"antiFlag":1,"message":"Forbid spider access"}`
- **Bing 图片搜索可用**：抓 HTML 后正则 `murl&quot;:&quot;(https?://...)&quot;` 拿直链
- **B 站内容拿不到**：专栏 API 返回 `-352` 风控，带 buvid3/buvid4 也过不去；`/read/cvXXX` 页面是 1.3KB 的 SPA 空壳；Bing 也索引不到 `hdslb.com` 的图
- **命中率极低**：两次搜索下载了 135 张，只有 3–4 张真是达妮娅，其余是其他角色、立绘、真人照
- **注意撞名**：搜到的「娜维娅Q版表情包」是**原神的娜维娅**，不是鸣潮达妮娅

## 换素材时的注意

- 支持的格式：`.png` `.jpg` `.jpeg` `.gif` `.webp` `.bmp`
- **文件夹名就是标签名**，中文没问题，和 `config.json` 里 prompt 写的标签一一对应
- 同一个文件夹放多张，每次随机挑一张
- 静态图 **300KB 以内**最好；**GIF 控制在 800KB 以内**，图片会转 base64 塞进消息（体积膨胀 33%），太大容易发不出去
- 文件名随意，`01.jpg` / `困死了.gif` 都行

## 空目录不会报错

标签对应的文件夹空了或者图坏了，bot 就只发文字，静默降级。所以大胆删、大胆换。
